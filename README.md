# Musubi Logic

## サイト概要
### サイトテーマ
経費・物品（貯蔵品）・資産・知見を繋ぐ、バックオフィス一元化プラットフォーム
​
### テーマを選んだ理由
現在の業務に携わる中で、経費精算、固定資産台帳、そして部材などの貯蔵品棚卸表がそれぞれ異なるシステムやExcelで管理されていることによる「情報の分断」に強い課題を感じてきました。
特に、備品購入時の経費精算が資産台帳や棚卸表と連動していないため、購入後の登録漏れや、在庫があるにもかかわらず重複して発注してしまうといった「二重買い」のヒューマンエラーが、多くの現場における共通の課題となっています。また、運用ルールに関する知見も属人化しやすく、管理部門には現場から「この金額は資産計上すべきか消耗品か」「インボイス制度上、この領収書で精算可能か」といった、過去に回答済みの類似質問が何度も寄せられ、本来の業務が圧迫されるという実態もありました。
そこで、経費・資産・貯蔵品、そして現場の知見を一つの線で結び、情報の整合性を自動で保つ仕組みを構築することで、バックオフィス業務を効率化したいと考え、このテーマにしました。
​
### ターゲットユーザ
・備品の在庫管理や資産登録漏れ、現場からの重複する問い合わせに悩む管理部門（経理・総務）の担当者  
・在庫の確認や申請ルールの把握に時間を取られている現場社員

### 主な利用シーン
・消耗品やオフィス備品を新たに購入・精算する時  
・備品の発注前に、社内の在庫状況や過去の購入先を確認する時  
・「この領収書は経費にできるか」など、判断に迷う申請を行う時
